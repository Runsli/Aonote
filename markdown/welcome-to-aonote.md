# 欢迎来到 Aonote 青笺

**Aonote 青笺** 是一个偏文档、偏博客的个人静态笔记站。这里会记录数据科学、Web 基础技术、自动化实践，以及围绕极简主义和长期写作的一些思考。

名字里的 `Ao` 取自“青”的音感，也保留一点轻微的造词感；`note` 则对应笔记、札记和持续记录。中文名“青笺”更偏写作意象：一张轻薄、安静、适合慢慢落字的纸。

## 为什么做这个站点

我希望这个网站首先是一个适合阅读的地方，而不是一个复杂的 Web App。它的目标很朴素：

- 内容应该长期可读。
- 页面应该快速、稳定、少干扰。
- 链接、订阅、归档和标签应该清楚可靠。
- 样式可以精致，但不应该抢走文字本身的位置。

# 技术取向

这个站点由 Python 脚本把 Markdown 生成纯静态 HTML 和 CSS。默认不输出可执行 JavaScript，也不依赖前端框架运行。

选择 no-JS 并不是为了追求形式上的克制，而是为了让页面更接近文档本身：打开即读、容易缓存、容易迁移，也更少受到运行时、构建链和第三方脚本的影响。

目前站点已经支持：

- Markdown 写作、目录、代码高亮、表格、脚注、任务列表和数学公式。
- 首页、归档、标签、RSS、Atom、Sitemap 和真实 404 页面。
- 浅色/暗色模式、移动端导航、键盘焦点样式和锚点滚动优化。
- 构建后健康检查，用来发现链接、SEO、无障碍和 no-JS 方面的问题。

## 未来会写什么

这个站点会围绕几个方向慢慢积累：

- **数据科学**：Python、Pandas、NumPy、数据清洗、数据可视化和建模基础。
- **Web 基础技术**：HTML、CSS、静态站生成、SEO、可访问性和性能优化。
- **自动化实践**：用 Python 和命令行工具减少重复劳动，保持工作流轻量。
- **建站日志**：记录这个站点从设计、构建到优化的过程。
- **个人笔记**：关于学习方法、工具选择、长期主义和极简生活方式的随笔。

## 阅读方式

你可以从首页按时间阅读，也可以通过归档和标签查找主题。喜欢订阅的话，可以使用 RSS 或 Atom，把更新放进自己的阅读器里。

希望 Aonote 青笺能成为一个安静、清晰、可长期维护的角落。它不追求热闹，只希望每一篇内容都尽量有用、准确，并且经得起以后回看。
